# 결과와 시험 조건

다음 값은 프로젝트2 보고서의 기록이며 이번 저장소에서 다시 측정한 결과가 아닙니다.

| 항목 | 보고서 결과 | 범위 |
|---|---|---|
| 수어 분류 | accuracy 약 88%, macro F1 약 0.88 | 800개 중 학습 640/validation 160, 클래스별 validation 8개인 PC 평가 |
| A DMA 처리 구간 | 약 176 µs/20 ms 프레임 | GPIO pulse로 관측한 프레임 계산 구간, 전체 장치 지연 아님 |
| A polling 취득 | ISR 약 1.2 ms | 타이머만 toggle한 약 124 µs 조건과 비교한 ADC polling 시험 |
| B ADC 관련 처리 | DMA 114 µs, 비DMA 9.04 ms | 보고서의 해당 ADC 구간 비교. 전체 시스템이 79배 빨라졌다는 뜻 아님 |
| 통합 시연 | 방향 LED·수어 LCD, 소음 모드, 간단어·S/V/O 문장 출력 | 보고서의 시연 서술과 영상 자료 |

## 시연

[시연영상](../media/demo.mp4)에서 센서 입력과 LED/LCD 출력의 연결을 볼 수 있으며, 주요 장면의 위치는 [시연 구간 안내](demo.md)에 정리했습니다. 이 저장소 제작 중 보드를 새로 실행한 영상은 아닙니다.

## 확인 범위

- 88%는 양자화 STM32 모델의 별도 현장 정확도나 사용자 독립 test 결과가 아닙니다.
- 방향별 각도·거리·소음 조건의 정량 정확도는 보고서에서 확인되지 않았습니다.
- 3채널 scan을 별도의 동시 샘플링 회로 성과로 확대하지 않습니다.
- DMA 구간 비교와 전체 SPI polling·분류·LCD 표시 주기의 검증은 다른 항목입니다.
- 공개한 A/B 소스와 보고서의 시험 설정이 모든 항목에서 같은 binary임을 재검증하지 않았습니다.

## 출처

프로젝트2 보고서 pp21–22·25–30, 실제 학습 스크립트·선별 STM32 소스와 상세 기술 기록. 동일 입력의 PC/MCU 모델 대응은 [실행 준비](reproduction.md)의 추가 확인 항목입니다.
